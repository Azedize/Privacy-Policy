# Privacy Policy

This repository contains the privacy policy documentation for the Chrome extension.

## Contents

- `privacy-policy.html` – the user-facing privacy policy document.

## Policy overview

The privacy policy describes how the extension handles permissions, data access, data storage, and security. It confirms that the extension does not collect, sell, or share personal information with third parties, and that local data is stored only in the user's browser unless explicitly stated otherwise.

## Usage

Open `privacy-policy.html` in a browser to view the full privacy policy.
